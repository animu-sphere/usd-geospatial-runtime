# USD Geospatial Runtime v0.1.0

Released 2026-08-28.

## Scope

The first release composes OpenUSD 26.08 with HTTP asset resolution, persistent
cache support, LAS/LAZ/PLY/COPC FileFormat plugins, and the GeoTIFF FileFormat
plugin. The supported composition target is
`windows-x86_64-msvc143-py313`.

## Acceptance

The seven inputs were pulled by immutable OCI digest into an empty OST_HOME and
composed without producer paths. SDK validation and all installed probes passed:

- HTTP: 73 cold body bytes, 0 warm body bytes, persistent cache hit.
- Point cloud: LAS, LAZ, PLY, and COPC opened and authored expected points.
- Tier 2: ten local/HTTP COPC scenarios passed; range reads occurred, strong
  ETag A/B revisions had distinct identities, and weak validators stayed unstable.
- Raster: the packaged 2 by 2 GeoTIFF opened as `tif`, with EPSG:32654 and the
  expected authored layer digest.

The same acceptance passed after pulling the composed artifact into an empty
registry and reconstructing it.

## Limitations

Python 3.13 is a host prerequisite. The release makes no Linux or macOS
composition claim. Synthetic fixtures do not establish large-file performance,
broad public-server interoperability, or geographic accuracy.
